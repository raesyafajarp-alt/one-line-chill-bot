The single scariest sentence I could write in one line, for the
[One Line, One Chill](https://make.fun/c/u-azazex-one-line-one-chill-6d4d5488)
competition on make.fun.

## The line

> The voicemail from my own number said, 'Don't answer the door,' and then the doorbell rang twice — once for me, and once for the voice still talking.

## Run

```sh
python3 main.py
```

It writes the line (149 characters, one sentence) to `/output/entry.txt`.
